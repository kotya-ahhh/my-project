# Майнул 🐾

Веб-приложение «виртуальный питомец»: манул Майнул живёт своей жизнью прямо в браузере — его
нужно кормить, мыть, укладывать спать, убирать за ним и баловать в мини-игре ради монет.

## Стек

Актуальные стабильные версии на момент разработки (сентябрь 2026):

| Слой       | Технология                          |
|------------|--------------------------------------|
| Рантайм    | Node.js 26                           |
| Клиент     | React 19, Vite 8, React Router 8     |
| Сервер     | Express 5                            |
| База данных| SQLite (better-sqlite3 13)           |
| Авторизация| JWT (jsonwebtoken) + bcryptjs        |

Графика питомца, иконок и комнаты нарисована в SVG «с нуля» в стиле присланных
логотипа и иконки (без внешних изображений), полностью на CSS-анимациях.

## Быстрый старт

Требуется **Node.js ≥ 26**.

```bash
npm install       # поставит зависимости сервера и клиента (npm workspaces)
npm run dev        # поднимет сервер (:3001) и клиент (:5173) вместе
```

Откройте `http://localhost:5173` — Vite сам проксирует запросы `/api/*` на сервер.
База данных SQLite создастся автоматически в `server/data/mainul.db` при первом запуске
(вместе со случайным секретом для JWT в `server/data/.jwt-secret`).

### Продакшен-сборка

```bash
npm run build       # соберёт клиент в client/dist
npm start           # запустит сервер в режиме production — он же отдаёт собранный клиент
```

Приложение целиком (API + статика + SPA-роутинг) будет доступно на `http://localhost:3001`.

### Переменные окружения (необязательно)

| Переменная    | По умолчанию              | Назначение                                   |
|---------------|----------------------------|-----------------------------------------------|
| `PORT`        | `3001`                      | Порт сервера                                  |
| `DB_PATH`     | `server/data/mainul.db`     | Путь к файлу SQLite                           |
| `JWT_SECRET`  | генерируется автоматически  | Секрет для подписи токенов                    |
| `TIME_SCALE`  | `1`                          | Ускорение игрового времени (для демо/тестов)  |

Пример быстрой демонстрации с ускоренным временем (1 минута = 1 игровой час):

```bash
TIME_SCALE=60 npm run dev
```

## Тесты

```bash
npm test
```

15 интеграционных тестов (`node --test`) поднимают сервер с in-memory базой и управляемыми
часами — проверяются убывание шкал, сон, следы, магазин, инвентарь и честность мини-игры
(результат и награда считаются на сервере, а не на клиенте).

## Структура

```
server/
  src/
    config.js        баланс игры — все числа в одном месте
    db.js             схема SQLite и стартовый каталог товаров
    petLogic.js        чистая логика убывания шкал/сна (без БД)
    petService.js       синхронизация питомца с БД
    routes/              auth, pet, shop, inventory, game
  test/                  15 интеграционных тестов

client/
  src/
    components/Pet.jsx    SVG-питомец Майнул (все настроения/действия)
    components/Icons.jsx  набор SVG-иконок в едином стиле
    components/Room.jsx   комната со следами жизнедеятельности
    game/engine.js         движок мини-игры «Лови еду» (без DOM)
    pages/                  Auth, Home, Shop, Inventory, Game
    styles/                  base / layout / pet / home / auth / shop / inventory / game
```

## Игровые правила (кратко)

- Четыре шкалы (0–100%): сытость, чистота, сон, радость — убывают со временем, даже пока
  вкладка закрыта.
- Раз в ~2 часа появляется след жизнедеятельности (максимум 3) — грязь и следы снижают
  чистоту и радость, пока не убраны.
- Во сне шкалы убывают втрое медленнее, а шкала сна восстанавливается; будильник — кнопка
  «Разбудить»/«Спать».
- Еда и лекарства покупаются в магазине за монеты и хранятся в инвентаре.
- Мини-игра «Лови еду» (45 секунд, 3 жизни) даёт монеты и радость, но немного утомляет —
  награда и результат проверяются на сервере, обмануть клиентом нельзя.
